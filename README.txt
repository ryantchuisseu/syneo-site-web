LES 7 PAGES

Contribuer (#contribuer) · Contact (#contact)

VOIR LE SITE SUR SON ORDINATEUR
Double-cliquer sur index.html (connexion Internet nécessaire pour les polices).

METTRE LE SITE EN LIGNE (au choix)
1. Netlify Drop (gratuit, 2 minutes) : aller sur app.netlify.com/drop
   et glisser le dossier SYNEO_site_web. Une adresse est donnée tout de suite.
2. Hébergeur classique (cPanel, o2switch, Hostinger…) : envoyer les 5 fichiers
   dans le dossier public_html, puis relier le nom de domaine (ex. syneo.cm).
3. GitHub Pages : créer un dépôt, y déposer les fichiers, activer Pages.

À SAVOIR
- Les formulaires (contribuer, contact) préparent un message WhatsApp vers le
  657 300 479 : aucun serveur n'est nécessaire.
- Les articles des rubriques sont des exemples à remplacer par de vrais contenus.
- Les montants de sponsoring (5 M à 30 M FCFA) sont à confirmer.
- Prochaine étape conseillée : un espace membre avec validation des contenus
  (CMS), à prévoir après le lancement du 18 novembre.
